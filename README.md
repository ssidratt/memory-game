# Memory Game

Memory Game is a classic card matching game. The goal is to find all matching pairs using as few moves as possible.

## Features

- 16 cards with 8 matching pairs
- Random card shuffle for every new game
- Moves counter
- Matched pairs counter
- Victory modal
- Leaderboard with the top 10 results
- Results saved in localStorage
- Responsive design

## How to play

1. Open the first card.
2. Open the second card.
3. If the cards match, they remain open.
4. If the cards do not match, they close automatically.
5. Find all 8 pairs to finish the game.

## Run locally

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.
